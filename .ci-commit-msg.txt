fix(ci): move config overlay to scripts/, repair broken workflow YAML

The previous commit inlined a Python heredoc into the workflow's run
block. Its lines started at column 1, which is outside the YAML block
scalar, so the whole workflow failed to parse:

    yaml.scanner.ScannerError: while scanning a simple key
    .github/workflows/release-oppo-module.yml, line 358

GitHub then reported "Workflow does not have 'workflow_dispatch'
trigger" because the file no longer parsed at all. Move the overlay
logic into scripts/overlay_config.py and call it from the run block.

Also regenerate device_full.config properly. The earlier copy was
captured through PowerShell's default UTF-16 encoding, which doubled its
size to 540106 bytes and injected U+FFFD replacement characters, so
every CONFIG_ line failed to match and the overlay silently parsed 0
device symbols. The file is now 260934 bytes of pure ASCII, and the
overlay reports 7395 device symbols.

Verified locally: MODULES, MODVERSIONS, MODULE_UNLOAD, FTRACE,
KALLSYMS_ALL, SYSFS, ARM64 and CFI_CLANG all keep the device's values.
